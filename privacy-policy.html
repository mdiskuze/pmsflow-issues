Privacy Policy - PMS Flow

Last updated: 2026-10-18

1. Overview

PMS Flow is a menstrual cycle tracking application for private, on-device use. This Privacy Policy explains what data the app processes and how.

2. Data Processed by the App

PMS Flow processes the following data entered by the user:

  • period dates and related cycle records
  • symptom logs (for example pain, mood, energy, notes)
  • pregnancy-related entries, if the user records them
  • basal body temperature entered by hand or, if the user allows it, read from Health Connect
  • local app preferences (notifications, prediction settings, app lock settings)

3. Where Data Is Stored

PMS Flow stores all data locally on the user's device.

PMS Flow does not require account registration and has no cloud synchronization. The developer has no server that receives your data.

4. Health Connect

If the user turns on the Health Connect import, PMS Flow asks Android for permission to read basal body temperature records. The permission is read only. PMS Flow never writes to Health Connect. The readings are copied into the app's local storage on the device and are used only to refine the ovulation estimate shown to the user. They are not sent anywhere. The user can withdraw the permission at any time in the Health Connect settings of the phone.

5. Data Sharing

PMS Flow does not sell user data and does not share it with advertising networks, analytics services or any other third party. The app contains no advertising or analytics code.

If the user explicitly uses export, backup or share features, the resulting file is created on the device and leaves it only through the sharing action the user chooses. If the user switches on the automatic backup, the app writes a backup file once a day into a folder the user picked on the device, and the file stays there until the user moves or deletes it. The user can protect JSON backup files with a password that is kept only on the device, in the Android Keystore. A shared snapshot is a read-only file for the person the user sends it to.

6. Network Access

The version of PMS Flow distributed through Google Play does not request internet access and makes no network connections.

The version distributed as an APK from the project's GitHub page checks GitHub for a newer release. That request contains no personal or cycle data. As with any web request, GitHub sees the IP address of the device.

7. Data Collection by the Developer

The developer does not collect personal cycle data. If this changes in a future version, this policy and the Google Play data disclosures will be updated before that version is released.

8. Security

PMS Flow offers an optional app lock (PIN or biometric unlock) to reduce unauthorized access on the device. Users are responsible for securing their device (screen lock, system updates) and for the files they export or share.

9. Data Retention and Deletion

Because data is stored only on the device, users can delete records directly in the app. Uninstalling the app removes its data from the device. Backup files (including the automatic backups in the folder the user picked) and shared snapshots that the user created earlier stay where the user saved or sent them.

10. Children

PMS Flow is intended for people aged 13 and over and is not directed at children under 13. The app collects no personal data from anyone, since all data stays on the device.

11. Medical Disclaimer

PMS Flow is not a medical device and does not provide medical advice, diagnosis or treatment. Predictions are estimates based on the history the user records. They are not a method of contraception.

12. Changes to This Policy

This Privacy Policy may be updated to reflect app changes, legal requirements or platform policies. The "Last updated" date shows the latest revision.
